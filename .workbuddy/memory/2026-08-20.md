## 修正：H5 城市选择弹窗右侧显示不全
- 用户截图（红框在弹窗右侧）反馈城市选择弹窗最右列城市被截断，显示不全。
- **根因**（`frontend/src/pages/user/index.vue`）：`.cp-grid` 使用 `grid-template-columns: repeat(4, 1fr)`，CSS 中 `1fr` 等价于 `minmax(auto, 1fr)`，城市名稍长就会把列宽撑开，整体超出弹窗宽度后被 `.city-picker` 的 `overflow:hidden` 截断。
- **修复**：
  1. `.city-picker` 宽度从 `84vw/640rpx` 略收到 `82vw/620rpx`，并显式加 `box-sizing: border-box; overflow: hidden;`。
  2. `.cp-list` 左右内边距从 `24rpx` 收到 `20rpx`。
  3. `.cp-grid` 改为 `grid-template-columns: repeat(4, minmax(0, 1fr))`，让列宽严格按可用空间分配，不能被内容撑开。
  4. 单元格 `.cp-item` 加 `min-width:0; overflow:hidden; text-overflow:ellipsis; white-space:nowrap; box-sizing:border-box;`，字号 `26rpx→25rpx`、左右 padding `6rpx→4rpx`、列间距 `16rpx→14rpx`，确保城市名即使较长也不会溢出。
  5. `.cp-item.loc`（重新定位）改为 flex 居中布局，避免图标+文字撑宽。
- 验证：`npm run build:h5`（frontend）→ `DONE Build complete.`。

## 修正：Web 搭配师端概览「没数据」
- 用户截图反馈整合进概览的数据看板（KPI + 三张图表）全部空白，问「咋回事，没数据」。
- **根因**（`frontend-web/src/views/stylist/Index.vue`）：图表用 ECharts 手绘（`renderDashboard()`），非响应式。
  - `onMounted` 里 `loadStats()` 是 async 但没 await，紧接着 `nextTick(renderDashboard)` 在数据回来前就用空 `stats` 渲染了一次空图。
  - 概览默认就是 `dashboard`，`watch(active)` 不会再次触发；而 KPI 是 `{{ stats.xx }}` 响应式能更新，但图表 `renderDashboard()` 此后再也没被调用 → 图表永远停在空数据。
- **验证后端**：`/api/stylist/stats` 返回 401（路由存在，新代码已部署），登录 stylist/123456 后实测返回 `total:42, avg_score:2.5, failed:5, fixed:4` 及完整的 rating_dist/error_dist/trend_7d —— 后端有数据，纯前端时序问题。
- **修复**：
  1. `loadStats()` 在 `stats.value` 赋值成功后 `nextTick(() => renderDashboard())` 主动重绘。
  2. 新增 `watch(stats, ...)`，只要统计变化且在 dashboard 视图就重绘图表（兜底，覆盖刷新/首次异步返回）。
  3. `loadStats` 的 `catch {}` 改为 `console.error` 以便后续排查。
- 验证：`npm run build`（frontend-web）→ `✓ built in 23.74s`。
- 预览：web `http://localhost:5176/`（stylist/123456）→ 概览，KPI 与三张图表现在都会随数据回填。
