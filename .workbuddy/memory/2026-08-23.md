## 时间显示时差 8 小时（用户截图"现在明明都晚上八点了"）

**根因**：后端 `created_at` 用 SQLite `server_default=func.now()` 存的是 UTC 时间，但 FastAPI/Pydantic 序列化后返回的 ISO 字符串不带 `Z`（如 `2026-08-23T11:48:26`）。前端 `new Date()` 把无偏移字符串当作本地时间解析，导致显示的时间比北京时间慢 8 小时。

**修复**：
- web 端 `frontend/src/views/user/Index.vue`：对话历史 `conv.created_at` 用 `fmtLocalTime()` 渲染。
- web 端 `frontend/src/views/stylist/Index.vue`：翻车案例/知识库上传时间同样用 `fmtLocalTime()` 渲染。
- H5 端 `frontend/src/pages/user/index.vue`：`fmtShortTime()` 在解析无偏移 ISO 字符串时自动补 `Z` 当作 UTC，再转为本地时间。

`fmtLocalTime` 逻辑：无偏移字符串视为 UTC → `new Date(iso + 'Z')` → 输出本地 `YYYY-MM-DD HH:mm:ss`。

**提交**：`2b0e0c0`。
