## 彻底修：场景推荐的加载器/弹窗 + 全程序配色统一为「蓝 + 薰衣草」

### 根因诊断（之前几次没修对的关键）
- **uni-app H5 的 scroll-view 会创建 containing block**（`will-change`/`transform`），导致里面的 `position: fixed` 相对 scroll-view 居中，而不是视口居中——所以前几次「`position:fixed` 居中」在跨滚动布局下无效。
- **全屏 mask 会拦截触摸**，所以加载/弹窗期间页面无法滚动。
- 用户明确要求：「配对色以外的颜色全部改掉」「按钮用配对色」「弹窗别那么大」「图标高级点」。

### 结构性修复（template + script）
- **把加载层和结果层从 `.home-panel`（scroll-view 内）搬到 `.page` 顶层**——彻底脱离 scroll-view 包含块，fixed 真正相对视口居中。
- **`<scroll-view class="main" scroll-y>` 加 `ref="mainScrollRef"`**，加 `scrollMainToTop()`：在 `runScene` 触发时把 scroll-view 滚回顶部，避免「点了分类但页面在下面」。
- **结果层 = 非交互式遮罩 `.scene-backdrop`（`pointer-events: auto` 仅用于点击关闭）+ 居中容器 `.scene-mask`（`pointer-events: none`）+ 卡片 `.scene-dialog`（`pointer-events: auto`）**——背景仍可滚动、点击遮罩关闭、卡片自身可点。
- **去掉 sheet-handle 和底部弹层样式**，结果改成紧凑居中卡片 `max-width:600rpx / max-height:72vh`，加 `sceneDialogIn` scale+fade 入场动画。

### 全程序配色统一为「蓝 + 薰衣草」（用户要求：配对色以外的颜色全部改掉）
- **首页分类图标**：`homeCategories` 改用 `linear-gradient` 背景，蓝 ↔ 薰衣草交替（约会/旅行/聚会 用薰衣草主导），让首屏一进来就看到配对色。

## 季节分布配色 fix（用户："这几个都没有区分开颜色"）

### 根因

- 即使改了 SEASON_COLOR 也没用，组合 key 没映射

### 修复
1. **seasonColorByKey 函数**：
   - 优先查 SEASON_COLOR 映射表（5 个单季 + 扩展 4 个组合 key）
   - 否则用 key 字符串 hash → 取模 8 调色板 → 自动分配三色系统里的独特色
   ```js
   const SEASON_PALETTE = ['#7aa8ff', '#FF9E8E', '#D4C0E8', '#5B8DEF', '#B19CD9', '#a9c6ff', '#E8DEF3', '#8B7AC0']
   function seasonColorByKey(k) {
     if (SEASON_COLOR[k]) return SEASON_COLOR[k]
     let hash = 0
     for (let i = 0; i < k.length; i++) hash = ((hash * 31) + k.charCodeAt(i)) | 0
     return SEASON_PALETTE[Math.abs(hash) % SEASON_PALETTE.length]
   }
   ```

## frontend-web 项目缺 index.html 导致 SPA 路由 404（用户："我页面呢？？？"）

### 根因
- 项目**从未 commit** 过 `frontend-web/index.html`（`git show HEAD:frontend-web/index.html` 报 path not exist）
- 但用户之前能在浏览器打开 `localhost:5175` —— 可能是宿主 IDE 里的 dev server 用了缓存或某 workaround
- 我用 `curl http://[::1]:5175/` 始终 404（无 index.html，vite 没有 SPA fallback 入口）

### 修复
1. `Stop-Process -Id 39356 -Force` 杀掉宿主 vite 进程（5175 端口空闲）
2. PowerShell `[System.IO.File]::WriteAllText` 写标准 vite-vue index.html（HTML 中含 favicon SVG data URI、id="app"、main.js 入口）—— 之前 Write 工具写入后没生效（怀疑 sandbox），PowerShell 直写成功（638 字节）
3. 后台启动 `npm run dev`（PID 38864）

### 验证
- `/` → 200 + 含 `/@vite/client` 注入
- `/config` `/login` `/stylist` 都 → 200（SPA fallback 正常）

### 教训
- vite 项目必须**有 index.html**（就算不用 Vite 模板也要自己写一个最小版）
- 用 curl 测 dev server 根路径 404 → 第一时间查 `ls index.html`，不要先怀疑被删坏了
