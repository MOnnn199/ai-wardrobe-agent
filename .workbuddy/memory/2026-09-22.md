## 修复 H5 三处 UI/定位问题（2026-09-22 11:08）

**问题1：Markdown 列表出现双层圆点**
- 根因：AI 输出里常自带 `·` 并加粗；`md2html` 把 `- ` 转成 `<li>` 后又让浏览器默认渲染了黑色 marker。
- 修复：ul/ol 加 `list-style:none; padding-left:0;`，li 用自定义蓝色 `::before` 圆点；同时清洗 li 内容前导的 `·/•` 字符避免重复。
- 相关：`frontend/src/pages/user/index.vue` `md2html()` + style 区 `:deep(.msg-text) ul/ol/li`。

**问题2：AI 消息/审核点评中文标题超出气泡**
- 根因：`.msg-text`、`.rv-c` 及内部 strong/h 没设置 `overflow-wrap/word-break`，长中文+标点组合时 rich-text 组件可能不自动折行。
- 修复：给 `.msg-text`、`.rv-c`、`:deep(... p/strong/h1/h2/h3/li)` 都加上 `word-break:break-word; overflow-wrap:break-word; white-space:normal/pre-wrap; max-width:100%; box-sizing:border-box`。`md2html` 生成的 strong/h 也内联同样的样式做兜底。

**问题3：自动定位失败（太平洋 ipjson.jsp 403）**
- 根因：`ipLocate()` 依赖 `whois.pconline.com.cn/ipJson.jsp?callback=...`，现在浏览器端返回 403；搜狐 JSONP 也偶有阻塞。
- 修复：保留太平洋做第一尝试（script 加载可能因网络被墙），新增**高德 IP 定位 API** 作为第一优先（有 VITE_AMAP_KEY 时），高德失败/返回空再 fallback 搜狐 `pv.sohu.com/cityjson?ie=utf-8`。`matchCity()` 能处理"福建省泉州市" -> "泉州"。
- 提交：`df13836 fix(h5): markdown 列表只保留一个圆点+文本防溢出+IP定位换高德/搜狐`

## 穿搭回顾头部返回箭头与标题错行（2026-09-22 13:45）
- 问题：进「穿搭回顾」独立面板，返回箭头 `<` 和标题「穿搭回顾」被拆成上下两行。
- 根因：`lookback-head` **漏了 flex 布局定义**，且模板缺 `head-right-spacer`。`.panel-head` 本身只是 `margin-bottom + position:relative`，不是 flex；`head-back` 是 `view`（块级）会把后面的 `panel-title`（text，行内）挤到下一行。`closet-head`（我的套装）之所以正常，是因为它有 `display:flex; justify-content:space-between` + 右侧 spacer 配平。
- 修复：
  - 模板补 `<view class="head-right-spacer"></view>`。
  - 把 `.closet-head, .lookback-head` 合并为**通用头部规则** `display:flex; align-items:center; justify-content:space-between`，移除 `closet-head` 的重复定义，并在注释里写明"新增此类头部必须引用本规则"。
- 结论：H5 带返回箭头的面板头部 = `panel-head + (closet-head|lookback-head) + head-back + panel-title + head-right-spacer`，五件缺一不可。
- 提交：`bb14f97 fix(h5): 穿搭回顾头部返回箭头与标题错行`。
